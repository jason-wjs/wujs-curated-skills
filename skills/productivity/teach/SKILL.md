# Teach

Use the learner's goal and demonstrated understanding to choose the next useful
lesson. An ordinary explanatory question does not require creating a course.
For an existing teaching workspace, read its mission and relevant learning
records; create missing artifacts only when they serve this learning session.

## Workspace resources

- `MISSION.md`: purpose and goals; [format](MISSION-FORMAT.md).
- `RESOURCES.md`: selected learning sources; [format](RESOURCES-FORMAT.md).
- `learning-records/`: demonstrated understanding and open gaps;
  [format](LEARNING-RECORD-FORMAT.md).
- `lessons/`: durable lessons when requested or established by the workspace.
- `reference/`: useful cheat sheets or glossaries; [glossary format](GLOSSARY-FORMAT.md).
- `assets/`: reuse existing styles or interactive components where helpful.
- `NOTES.md`: learner preferences that should persist.

Give each lesson a manageable objective and an opportunity to apply or retrieve
what was learned. Adjust challenge using the learner's response, not a fixed
lesson sequence. Use spacing and retrieval when they fit the goal. Verify
specialized or changing facts with good sources.

Use the format best suited to the lesson. HTML is useful for interactive or
reusable lessons, but not required for every explanation. Build shared components
when reuse exists, not before it. Record what the learner actually demonstrated,
not merely what the lesson covered. Offer a next step tied to the goal.
