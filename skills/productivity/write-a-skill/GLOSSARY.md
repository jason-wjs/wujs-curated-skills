# Skill Terms

- **Trigger**: the task conditions under which a skill should be selected.
- **Entrypoint**: `SKILL.md`, containing discovery metadata and essential guidance.
- **Progressive disclosure**: reading conditional material only when relevant.
- **Reference**: supporting knowledge reached by a link from the skill.
- **Invocation policy**: whether the harness may automatically select a skill.
- **Completion criterion**: an observable outcome tied to the requested task.

Use ordinary language; these terms do not impose a mandatory document structure
or claim that every harness loads metadata in exactly the same way.
