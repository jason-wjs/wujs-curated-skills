# Productivity

General workflow skills that are not tied to a specific codebase tool.

- **[grill-me](./grill-me/SKILL.md)** — User entry for a grilling session without writing project docs.
- **[grilling](./grilling/SKILL.md)** — Relentless one-question-at-a-time interview loop (shared by grill entry points).
- **[handoff](./handoff/SKILL.md)** — Compact the current conversation into a redacted handoff document for a fresh agent.
- **[teach](./teach/SKILL.md)** — Create and maintain a stateful teaching workspace with missions, lessons, resources, references, assets, and learning records.
- **[write-a-skill](./write-a-skill/SKILL.md)** — Create or improve agent skills with predictable structure, progressive disclosure, and bundled resources.
