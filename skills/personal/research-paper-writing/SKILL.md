# Research Paper Writing

Preserve the paper's technical claims and evidence. Clarify the contribution,
then improve the requested section's structure and prose. Give each paragraph
a clear purpose and introduce terms before relying on them. Preserve useful
methodological caveats; remove repetitive reviewer-facing defenses.

Match the task's scope. A paragraph edit does not need a full-paper review,
new figures, or a claim table. For a substantial draft, use reverse outlining
to check argument flow. Weaken or flag unsupported claims instead of inventing
results. Distinguish missing evidence from writing problems.

## Section guidance

Load only relevant references:
- [Abstract](references/abstract.md)
- [Introduction](references/introduction.md)
- [Related work](references/related-work.md)
- [Method](references/method.md)
- [Experiments and presentation](references/experiments.md)
- [Conclusion](references/conclusion.md)
- [Whole-paper review](references/paper-review.md), when requested
- [Paragraph flow](references/does-my-writing-flow-source.md)
- [Examples](references/examples/index.md), when a concrete pattern helps

Return the requested draft or revision. Add a short explanation of consequential
changes and evidence gaps when useful. Include outlines, paragraph-role labels,
or claim-evidence maps only when they help the requested deliverable. Full-paper
review should prioritize substantive risks, not append a checklist to every edit.
