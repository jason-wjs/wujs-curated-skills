# Edit Article

## Workflow

### 1. Section Map

Divide the article by its headings. For each section, identify:

- The main point the section should make.
- The key information it depends on.
- The information later sections depend on.

Treat the article as a directed acyclic graph of ideas. Reorder sections or
section contents so prerequisites appear before dependent claims.

Before rewriting, confirm the section map and proposed order with the user.

### 2. Rewrite Sections

For each section:

1. Rewrite for clarity, coherence, and flow.
2. Keep each paragraph at 240 characters or fewer.
3. Preserve the author's intended argument unless the user asks for a stronger
   restructuring.
4. Prefer concrete nouns and verbs over vague transitions.
5. Remove repetition unless it is serving emphasis.

After rewriting a section, move to the next section only when the user accepts
the direction or asks for specific changes.

## Editing Rules

- Preserve facts, citations, names, and technical terms unless they are clearly
  wrong or the user asks to change them.
- If a sentence is ambiguous, rewrite it only when the intended meaning is
  inferable from context. Otherwise ask.
- Do not add new claims without marking them as suggestions.
- Keep the article's target audience and tone consistent across sections.
