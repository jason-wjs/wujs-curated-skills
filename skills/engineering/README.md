# Engineering

General engineering behavior and code-work skills.

- **[code-review](./code-review/SKILL.md)** — Two-axis review (Standards + Spec) of the diff since a fixed point.
- **[codebase-design](./codebase-design/SKILL.md)** — Shared vocabulary for designing deep modules, seams, and adapters.
- **[diagnosing-bugs](./diagnosing-bugs/SKILL.md)** — Disciplined diagnosis loop for hard bugs and performance regressions.
- **[domain-modeling](./domain-modeling/SKILL.md)** — Actively sharpen domain language and record ADRs / CONTEXT.md.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — Grilling session that also runs domain-modeling.
- **[implement](./implement/SKILL.md)** — Build a spec or ticket with tdd and code-review.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** — Find deepening opportunities that make code more testable and AI-navigable.
- **[karpathy-guidelines](./karpathy-guidelines/SKILL.md)** — Lightweight guardrails for non-trivial coding, review, and refactoring where hidden assumptions, overengineering, broad diffs, or weak verification could cause mistakes.
- **[research](./research/SKILL.md)** — Investigate a question against primary sources and save cited findings.
- **[tdd](./tdd/SKILL.md)** — Test-driven development with a red-green-refactor loop and behavior-focused tests.
- **[to-spec](./to-spec/SKILL.md)** — Synthesize the current conversation into a published spec.
- **[to-tickets](./to-tickets/SKILL.md)** — Break a plan or spec into tracer-bullet tickets with blocking edges.
- **[zoom-out](./zoom-out/SKILL.md)** — Ask for a higher-level map of unfamiliar code and its relevant modules and callers.
