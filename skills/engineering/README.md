# Engineering

General engineering behavior and code-work skills.

- **[diagnose](./diagnose/SKILL.md)** — Disciplined diagnosis loop for hard bugs and performance regressions.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — Stress-test a plan against project domain language and ADRs, updating documentation as decisions crystallize.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** — Find deepening opportunities that make code more testable and AI-navigable.
- **[karpathy-guidelines](./karpathy-guidelines/SKILL.md)** — Lightweight guardrails for non-trivial coding, review, and refactoring where hidden assumptions, overengineering, broad diffs, or weak verification could cause mistakes.
- **[tdd](./tdd/SKILL.md)** — Test-driven development with a red-green-refactor loop and behavior-focused tests.
- **[zoom-out](./zoom-out/SKILL.md)** — Ask for a higher-level map of unfamiliar code and its relevant modules and callers.
