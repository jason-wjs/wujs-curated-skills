# Compare Interface Designs

For a consequential interface decision, compare genuinely different approaches
against the same real callers, constraints, failure behavior, and test needs.
Show a usage example and the trade-offs of each. Avoid adding flexibility for
imaginary consumers just to make alternatives look different.

Work locally by default. Independent agents are optional when authorized and
supported by the harness. Their number is determined by useful independent work,
not a quota. Recommend a design based on current needs and explain what would
make another option preferable.
