# Presentation Making

Apply the [shared editing defaults](../general-writing/references/editing-contract.md) to the requested passage.

Use the audience, time, source material, and requested format to shape the talk.
For a new deck or major restructure, consult
[deck workflow](references/deck-workflow.md). For layouts or rendered review,
consult [visual design review](references/visual-design-review.md). A narrow
text edit does not need both references.

Keep each slide focused on a point the speaker can explain. Preserve source
facts and notation; place supporting detail in notes when it would crowd the
slide. Follow a supplied template and retain editable objects or compilable
source. Use available presentation tools for the requested artifact.

For a produced or modified deck, render and inspect affected slides and check
overall consistency before delivery. Fix clipping, tiny text, notation errors,
and accidental overlap. State when rendering is unavailable. Return the deck,
editable source, and material unresolved content questions.
