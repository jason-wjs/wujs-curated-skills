# Writing

Choose the entry matching the requested output. An explicitly selected skill
bypasses this router. Read only the relevant skill and its task-specific
references; routing does not start a chain of editing passes.

| Request | Entry |
| --- | --- |
| General prose editing | [general-writing](../general-writing/SKILL.md) |
| Paper or section drafting and revision | [paper-writing](../paper-writing/SKILL.md) |
| Abstract only | [abstract-writing](../abstract-writing/SKILL.md) |
| Reviewer response | [rebuttal-writing](../rebuttal-writing/SKILL.md) |
| Literature synthesis and source verification | [literature-review](../literature-review/SKILL.md) |
| Grant story and feasibility | [grant-planning](../grant-planning/SKILL.md) |
| Grant application text | [grant-writing](../grant-writing/SKILL.md) |
| Slides and speaker notes | [presentation-making](../presentation-making/SKILL.md) |
| Prompt rewriting | [prompt-improving](../prompt-improving/SKILL.md) |
| Human writing manual | [improve-human-writing-guide](../improve-human-writing-guide/SKILL.md) |

For a targeted diagnosis, use [academic voice](../academic-voice/SKILL.md),
[defensive phrasing](../anti-defensive-writing/SKILL.md),
[semantic usage](../better-usage/SKILL.md), [cadence](../writing-cadence/SKILL.md),
[whole-draft transitions](../non-autoregressive-writing-pass/SKILL.md), or
[formulaic prose](../humanizer/SKILL.md) only when that is the task.

Infer the route from the artifact. Clarify only when the choice would materially
change the output. A talk about a paper is a presentation task. Human guides
are optional companion artifacts, not instructions for ordinary writing.
This collection does not yet contain patent-specific guidance.
