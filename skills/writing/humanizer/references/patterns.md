# Formulaic prose diagnostics

Adapted from the Humanizer catalog by Siqi Chen and its modifications in
academic-writing-skills. See the license files in the parent directory.
These are contextual diagnostics, not universal bans or AI-authorship tests.

| Pattern | What to examine | Revision direction |
| --- | --- | --- |
| Importance puffery | Pivotal, transformative, vital without a concrete result | State the supported result |
| Superficial analysis | Trailing highlighting/underscoring clauses add no explanation | Name the actual relation or remove the clause |
| Vague attribution | Experts agree, studies show | Name the supplied source or flag the missing evidence |
| Promotional register | Marketing language in research exposition | Describe the mechanism or comparison |
| Ornamental contrasts | Repeated not-X-but-Y frames | State the point directly; retain substantive distinctions |
| Synonym cycling | Several names for the same technical object | Repeat the stable term |
| Formulaic rhythm | Identical openings, stacked fragments, repeated summaries | Organize around the actual reasoning |
| Loose catalogs | Items lack a common relation | Explain the relation or separate distinct claims |
| Abstract wrappers | The interplay/role of X obscures what happens | Use a direct relation when evidence permits |
| Semantic mismatch | The claim stops, the evidence performs an analysis | Identify the actor or affected property |
| Stale display text | Heading promises something the section no longer covers | Match the completed argument |
| Unsupported specificity | A rewrite adds a number or setting | Restore the source's actual information |

Examples:

- “This result marks a pivotal milestone” can become the actual result when
  supplied, or lose the empty evaluation. Do not manufacture a result.
- “The protagonist … the main character … the central figure” may use one
  stable designation when all refer to the same person.
- “This is not X. It is Y.” can state Y first if rejecting X contributes
  nothing. Keep X when it defines a scientific boundary.

A list, dash, passive voice, ordinary relative clause, or repeated term may be
exactly right. Preserve the author's voice rather than creating new verbal tics.
