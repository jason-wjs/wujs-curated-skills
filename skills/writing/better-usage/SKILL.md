# Better Usage

Apply the [shared editing defaults](../general-writing/references/editing-contract.md) to the requested passage.

Identify the intended relation before replacing a word. Check whether the
subject can literally or conventionally perform the action and whether the
object fits it. Name an omitted intermediate only when it is supported: a
condition may limit a claim's extent rather than make the claim stop.

Preserve accepted shorthand such as a theorem implies or evidence supports.
Do not imply that an analysis, review, or experiment occurred when none was
supplied. A more precise verb must not strengthen evidential force.

Use [compatibility examples](references/compatibility-examples.md) for a
semantic diagnosis, not as a substitution dictionary. Return the local repair
or requested findings; do not initiate a broader prose workflow.
