# Grant Planning

Apply the [shared editing defaults](../general-writing/references/editing-contract.md) to the requested passage.

Develop the scientific argument from the call, evaluation criteria, applicants'
prior work, and available resources. Separate facts, hypotheses, and unresolved
decisions. Do not polish a missing premise into apparent coherence.

Compare genuinely distinct stories by importance, sponsor fit, preliminary
evidence, team contribution, scope, and feasibility. Explain the scientific
dependency between applicants rather than listing their publications. Identify
the first decisive test and what an informative negative result would teach.

Use [planning-template.md](references/planning-template.md) for a substantial
comparison, and [sponsor types](../grant-writing/references/sponsor-types.md)
when fit matters. Retrieve primary sources only as needed; use a versioned
archive when source-level inspection helps. Extract archives into task-local
folders, rejecting traversal paths and links escaping the destination. Keep
private material outside the skills collection; do not change repository-wide
ignore or tracking rules merely to inspect a source.

Return the recommended argument, alternatives worth retaining, evidence safe
to use, feasibility limits, and open author decisions. Draft the application
through [grant-writing](../grant-writing/SKILL.md) only when the user requests
that next deliverable or has already authorized it.
