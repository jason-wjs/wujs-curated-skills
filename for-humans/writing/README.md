# Writing materials for people

These are human-facing documents, not installable agent skills. Agent entrypoints
live in [skills/writing](../../skills/writing/README.md). The installer does not
copy this directory into any harness.

- [Research-paper guide](human-writing-guide/README.md): editable LaTeX and
  [published PDF](human-writing-guide/human-writing-guide-main.pdf).
- [Human and agent writing](human-vs-agent-writing/README.md): comparison and
  worked revisions, with [published PDF](human-vs-agent-writing/human-vs-agent-writing-main.pdf).
- [Raw LaTeX template](raw-latex-template/README.md): a standalone paper starter
  and [rendered example](raw-latex-template/latex-template-main.pdf).

Imported from academic-writing-skills at revision
`9ff8f95b790a0e47809a172963c4c4417443f9b8`. Source, bibliography, image, and PDF
bytes are preserved; companion READMEs reflect the new location. These published
guides may describe earlier editing heuristics. Use the current agent skills
for runtime behavior. See [acknowledgments](ACKNOWLEDGMENTS.md) and [license](LICENSE).

Private papers, grant applications, and patent materials are not included.
Use the build instructions inside each project when changing its source;
copying unchanged sources and PDFs does not require regenerating them.
